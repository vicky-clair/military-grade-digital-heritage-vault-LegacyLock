# LegacyLock (遗产保险锁)

> 军规级数字遗产保险箱 · 两个U盘同时插电脑解锁

LegacyLock 是一款面向家庭与个人的高安全等级**数字遗产保险箱**桌面应用。用户生前设置继承计划与数字资产库，在继承触发时，继承人必须**同时拥有用户U盘与继承人U盘**插入电脑，经双重物理隔离与加密校验后方可安全激活并解密数字资产。

---

## 核心特性

- **物理隔离双钥匙机制**：基于 Shamir / 双向物理密钥隔离设计，必须同时插上两个硬件 U 盘才可执行解密。
- **军规级加密体系**：X25519 密钥交换 + ChaCha20-Poly1305 / AES-256-GCM + Argon2id 密码衍生。
- **时间戳与失效防滥用**：支持设置继承生效期与失效时间戳，服务器仅存储加密哈希与时间戳，杜绝明文风险。
- **跨平台桌面端体验**：现代化桌面应用界面，支持多分类数字资产存储（账号密码、加密备忘、支付资产、数字密钥等）。

---

## 架构简述

```text
[云端/服务节点] <--- SHA256(加密主密钥) + 失效时间戳 --- [继承人公钥比对]
                     |
                     | 必须同时满足
          两个U盘（用户U盘 + 继承人U盘）插电脑
                     |
   [继承人本地] <--- 解密 AES-256-GCM 数字资产 --- [本地离线密文库]
```

---

## 开发路线 (Roadmap)

- **Phase 1**: Rust 核心加密模块 + 两个 U 盘密钥生成/验证 CLI + 桥接层
- **Phase 2**: 密码库 UI (React + Tailwind) + 主密码 Argon2id + 计划继承配置
- **Phase 3**: 双 U 盘插入实时侦测与解锁流 + 本地资产密文库存储
- **Phase 4**: 导出备份、数字资产自动导出迁移与扩展凭证支持
