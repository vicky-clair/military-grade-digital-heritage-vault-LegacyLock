# 信息备份、主副盘、三语言与托盘修复说明

日期：2026-09-21。基于现有 LVCF 3 实现继续修改，保留原侧栏、资产卡片、24 类模板、附件、自定义字段、五套背景和订阅测试界面。

## 本次实现

1. **信息数据导出与导入**：在「加密导入导出」明确区分 `.llvault` 信息备份与 `.llkey` 解锁材料。信息备份包括加密的登录信息、备注、附件、自定义字段和密库设置。导出重新验证密码与安全密钥。没有两份 USB 秘密写入信息备份。
2. **两个认证入口**：密码＋安全密钥授予所有者管理；双 USB 选择备份只读访问。移除“双盘直接打开本机密库”、重复导入入口和旧迁移 IPC/UI，保留维护者离线旧格式恢复代码。
3. **只读不覆盖本机**：双盘导入仅创建内存会话，可查看其他密库或历史文件；不替换本机数据。接管管理必须验证原备份双凭据，并通过本机身份和防回滚检查。
4. **合并信息**：已解锁所有者用源文件双凭据验证后合并。现有设置、身份及 USB 配置不变；完全一致记录跳过，ID 冲突保留为新副本。
5. **副盘固定**：首次配置副盘仅写 `secondary.llkey`；日常更新只需要主盘。保存资产、更新设置和更换密码/安全密钥不改副盘。现有 LVCF 3 份额兼容，不必为升级重配；副盘上的旧版加密备份不会自动删除。显式“重新配置两盘”才轮换整套恢复秘密和数据密钥。
6. **删除本机密库**：设置页去掉重复凭据入口，提供双确认删除。第一步重新验证双凭据；第二步单次随机令牌、两分钟时限、绑定会话和版本，要求输入 `DELETE`。仅删除本机密库、回退副本和专属临时文件，不扫描或删除外部备份与 USB。
7. **中英日与托盘**：新增流程、订阅、错误提示和原生文件对话框接入翻译。所有者保存语言和托盘偏好；锁定/继承会话只可临时选择显示语言。默认关闭即退出，可选择关闭即锁定后常驻托盘。托盘支持打开、锁定、退出；创建失败不隐藏唯一窗口。

## 安全边界

沿用固定参数 scrypt、随机 256 位安全密钥、AES-256-GCM 与 Ed25519，不引入公开恢复种子或单凭据解锁。已配置双盘是明确授权的另一读取方式，不是“无密码就永远无法解密”。签名私钥不在双盘恢复槽中，主进程继续拒绝继承者写入和设置修改。

不承诺“绝对无法破解”。系统被控制、凭据泄露、USB 秘密被复制或明文被另存，均在实际风险范围内。更换凭据不追溯更新旧导出文件；旧双盘仍能读取旧代次备份。

“删除本机密库”不是所有介质的物理安全擦除。SSD、文件系统残留、系统快照、外部备份与已保存附件不能由本应用保证不可恢复，界面明确提示此限制。

## 建议用户测试顺序

先用测试密库：配置两盘后取下副盘，新增登录信息和备注，仅更新主盘；再插回副盘只读导入主盘备份，检查新数据和只读限制。然后测试改密码与安全密钥、再更新主盘，确认原副盘仍能配合读取。不要点击“重新配置两盘”代替普通更新。

导出 `.llvault` 后在另一系统账户导入，验证错误/缺少任一凭据被拒绝，正确双凭据可编辑，双盘仅可查看。最后仅在无重要数据的测试密库中测试删除和外部备份保留。
