# 1.0.1 界面、启动与项目精简维护报告

## 用户反馈处理

- “旧备份”和“本机没有数据”由用户确认是误导入，不再处理；未修改身份检查、防回滚或现有数据。
- 卡片和只读详情不再渲染未填写的自定义字段，包括空字符串和纯空白。值为 `0` 的字段仍显示；模板及已保存内容没有被删除。
- 关闭主窗口恢复主进程原生提示：锁定并隐藏至托盘、退出应用、取消。设置项控制默认选项，不跳过提示；托盘创建失败保留窗口。直接退出与系统退出继续先锁定并等待写入队列。
- 删除编辑器“添加网站”快捷按钮及其专用事件入口；“添加更多”中的 URL 类型保留。
- 调整工具栏、卡片复制/显示按钮、操作行及表单间距，改善卡片边框、圆角、阴影和键盘焦点。维持侧栏、主题、订阅、分类、附件和双盘备份布局。
- 保留 Electron 主进程单实例锁，第二次启动恢复已有窗口。测试实际启动另一个 Electron 进程，确认不能取得同一用户数据目录的锁；不宣称阻止其他系统账户运行独立密库。

## 代码与文档清理

对当前入口做 TypeScript 导入图遍历、构建、类型检查和回归，删除 15 个未引用的旧文件：

`ChangePasswordModal`、`CloseConfirmModal`、`HealthCheckModal`、`HeirRecoveryView`、`ImportExportView`、`LockScreen`、`MediaMigrationModal`、`SetLockPasswordModal`、`SettingsView`、`TakeoverControlModal`、`UsbPasswordModal`，以及 `clipboardService`、`cryptoService`、`mockData`、`subscriptionService`。

旧关闭组件已由原生主进程提示替代。旧密码学、模拟数据与浏览器角色代码不再留在前端源码树。删除未使用的旧类型模型、翻译分组和 clsx 依赖。再次遍历当前 `src/main.tsx` 入口后，没有未引用的 TS/TSX 文件。

删除根目录两份过时设计草案 `military-grade-digital-heritage-vault-LegacyLock.md` 和 `military-grade-digital-heritage-vault-LegacyLock2.md`，其架构和部分安全宣传与现有 LVCF 3 不符。更新 README、用户手册、开发说明与权限表。保留协议、有效操作手册、历史审计证据、独立阅读器及旧数据抢救源码；不删除密库、USB、备份、`vault.locked` 或用户数据。

`vault-migrate.cjs` 保留供维护者离线恢复，但不再进入发布包。共享 CSS 中无法安全确认无引用的规则未盲删，避免破坏动态类别、响应式与弹窗样式。

## 启动和包体积

资产列表、编辑器、分类选择及订阅界面按需加载，每个区域独立等待，避免加载弹窗时整个应用界面被替换。首次加载 JavaScript 从约 454 KB 降至约 327 KB（未压缩资源）。

React 与图标库已由 Vite 编译打包，改为构建依赖，不再把整份 npm 运行目录重复带入应用。Electron 运行时、沙箱与完整性校验仍保留，没有通过削弱加密参数或删除运行时组件减重。

同一机器、相同 Electron、全新隔离用户目录，交替运行旧版与新版各三次：旧版首屏 545/606/604 ms，中位 604 ms；新版 539/686/546 ms，中位 546 ms。仅是空密库首屏测量，样本较少，不能保证所有机器快 10%；不含便携 EXE 的自解压时间。测量脚本为 `scripts/measure-startup.cjs`，记录为 `startup-comparison.txt`。

## 验证和安全结论

- 28 项核心测试通过：双凭据、篡改拒绝、双盘只读、主盘单独更新、副盘不变、文件写入故障、导入合并、删除确认和偏好权限。
- 桌面回归通过：第二进程锁、实际表单、按需加载、隐藏空字段但保留 `0`、去除网站快捷入口、三语言、背景、订阅演示、800×500 布局、托盘提示取消及隐藏、继承者 IPC 权限拒绝。
- 当前源代码通过 TypeScript/Vite 构建及 `git diff --check`。截图位于 `polished-ui/`，日志为 `tests-polished.txt`、`desktop-polished.txt`、`build-polished.txt`。
- 本轮复核当前发布路径、引用关系、主进程权限、密码学参数和保存流程。不是独立第三方完整密码学审计，也不能证明软件绝无缺陷。

LVCF 3、scrypt N=32768/r=8/p=1、随机 256 位安全密钥、AES-256-GCM 和 Ed25519 均未降级。正常数据解密仍需所有者密码＋安全密钥，或已配置的双份 USB 秘密只读恢复。两盘配置和备份兼容，不需要升级后重配。

无法承诺“第三方绝对无法破解”：凭据或双盘秘密泄露、系统被控制、已解密数据被另存等风险仍存在。文件删除、系统快照、SSD 残留的边界仍按协议和界面明确说明。

本次在 Windows 验证；macOS/Linux 的真实设备、安装和原生托盘仍需实机验收。

## 发布包核对

输出为 `release/1.0.1-polished/`。应用代码包 app.asar 从 32,782,195 字节缩至 587,723 字节；完整 Windows 安装包从 94,072,463 字节缩至 92,860,447 字节，便携包为 92,630,446 字节。完整包仍主要由 Electron 运行时占用，不把代码包缩减比例当成安装包缩减比例。

安装包和便携包均通过 7-Zip 完整性检查。包内全部发布主进程模块、翻译、前端构建资源和离线阅读器逐字节匹配本次源码；确认没有 node_modules 或旧迁移模块。记录在 `package-polished-integrity.txt`，SHA-256 在发布目录 `SHA256SUMS.txt`。Authenticode 检查为 NotSigned，仍属于未做发行签名的测试构建。
